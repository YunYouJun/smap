# 设计沉淀

本文记录 SMAP 的产品设计、移动端 UI/UX 原则和技术边界，作为后续迭代的共同依据。

## 产品定位

SMAP 是一个星际导航地图应用原型。它的核心不是展示一张科幻海报，而是让用户像使用真实地图 App 一样完成出行决策：

1. 输入起点和终点。
2. 查看地图上的路线与路况。
3. 在底部 sheet 中比较路线方案。
4. 选择导航、打车或探索附近服务。
5. 在“我的”页管理账号、收藏、订单和偏好。

## 信息架构

移动端主 Tab：

```text
导航      以地图和路线规划为核心
打车      复用当前起终点，选择快船服务
探索      展示附近补给、维修、住宿和风险点
我的      YunLeFun 登录、收藏、订单、导航偏好
```

页面层级：

```text
IonApp
└─ IonRouterOutlet
   └─ IonTabs
      ├─ /tabs/map
      ├─ /tabs/ride
      ├─ /tabs/explore
      └─ /tabs/profile
```

## 移动端 UI 原则

- 第一屏优先是地图，不做营销 hero。
- 顶部只放路线搜索浮层，不放登录、宣传或复杂设置。
- 右侧地图按钮保持短路径操作，例如定位、缩放、图层。
- 底部 sheet 承载路线方案、路线偏好和主 CTA。
- “我的”页集中账号能力，YunLeFun 登录不进入地图第一屏。
- Tab 控制在 4 个，符合移动端底部导航的认知负担。
- 触控目标不小于 44px，避免小图标难点。
- 默认浅色地图体验，暗色模式跟随系统。

## 地图 App 参考边界

SMAP 会参考真实地图应用的通用模式：

- 路线输入卡片。
- 地图控件悬浮。
- 路线方案横向比较。
- 底部导航 Tab。
- 打车服务嵌入出行上下文。
- 我的页承载登录、订单、收藏和设置。

但不会直接复制任何具体地图产品的品牌、商标、图标、地图瓦片、命名体系或专有视觉资产。视觉上应靠近“真实地图工具”，而不是靠近某个品牌的 1:1 复刻。

## 视觉语言

移动端：

- 地图底色：浅灰绿、低饱和道路网。
- 主路线：蓝色。
- 起点：绿色。
- 终点和价格：橙色。
- 拥堵/风险：红橙色。
- 面板：白色或暗色 surface，轻阴影，圆角克制。
- 主按钮：蓝色圆角胶囊。

桌面端：

- 可以保留更强的星际驾驶舱感。
- 左侧路线规划、中央星图、右侧遥测信息形成工作台布局。
- 不要求完全贴近移动地图 App。

## 组件职责

```text
SmapNavigator
  组合状态和子组件，不承载具体视觉细节。

SmapTopBar
  桌面品牌导航 + 移动端路线输入浮层。

StarMapCanvas
  地图画布、路线、风险区、地点标牌和地图控件。

MobileNavigationSheet
  移动端底部 sheet，包含导航、打车、探索、我的四类内容。

SmapAccountStatus
  YunLeFun 登录状态和登录动作；在“我的”页中以 profile 形态展示。

useSmapNavigation
  路线、服务、选中状态、地图工具和交互动作的组合式状态。

@yunyoujun/smap-sdk
  第三方接入 SDK，提供路线、地点、图层、事件和默认内存数据源。

smapData adapter
  子应用内的 SDK 适配层，把 SDK 返回的领域数据转换为导航页、打车页和探索页需要的 UI view model。
```

## 登录设计

登录不放在地图顶部，原因：

- 地图首页最重要的是路线决策。
- 账号不是出行主流程的前置条件。
- 登录入口在“我的”页更符合地图类 App 的信息架构。
- 后续收藏、订单和偏好都能自然挂在个人中心下。

## 打车设计

打车不是独立应用，而是路线规划的补充服务：

- 默认复用当前起点和终点。
- 展示车辆类型、接驾时间、送达时间和价格。
- 支持从路线 sheet 里的“打车”卡片直接切换。
- 订单记录沉淀到“我的”页。

## 部署策略

SMAP 子应用优先静态托管：

```text
Build command: pnpm app:generate
Output directory: apps/smap/dist
```

这使它可以部署到 EdgeOne Pages、Cloudflare Pages 或其他静态托管平台。鉴权相关逻辑保持浏览器端执行。

## SDK 设计

`packages/smap-sdk` 是对外接入层，不直接绑定 Nuxt、Vue 或 Ionic。它应该保持无运行时依赖，并优先暴露稳定的 TypeScript 类型：

- `SmapWaypoint`：地图地点和跃迁点。
- `SmapRoute`：路线方案。
- `SmapPoi`：附近服务点。
- `SmapLayer`：地图图层状态。
- `SmapClient`：路线规划、POI 查询、图层开关和事件订阅。
- `SmapDataSource`：第三方自定义数据接入点。

未来如果接入真实地图服务，优先替换数据源和 route planner，不要把渲染层能力塞进 SDK core。
